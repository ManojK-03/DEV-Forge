01 / The CommunityP. 003

A workshop for people who make things.

everyone starts somewhere ↗

DEV Forge runs on a simple belief: the best way to learn software is to make something with other people. We gather to study the fundamentals, write code side by side, and turn half-finished ideas into things that actually run.

Everyone is welcome at the bench — whether you are writing your first loop or reviewing your fortieth pull request. Beginners learn from builders, builders learn by teaching, and every project gets a second pair of eyes.

“Learn it on paper. Write it in code. Ship it with friends.”
  • i.

    Learn

    Structured study across algorithms, the web, programming and AI.

  • ii.

    Code

    Regular practice sessions and problem-solving evenings.

  • iii.

    Build

    Team projects that travel from first sketch to deployed product.

  • iv.

    Grow

    Mentorship, open source and preparation for internships.

03 / The Learning JourneyP. 008

Five stages, annotated.

A field guide for the road from curious beginner to confident builder. Move at your own pace; every stage ends in something you can show.

notes in the margin →
  1. I
    Stage 01 / 05

    Foundations

    Learn how a computer thinks. Variables, loops, functions and logic in one language, plus the terminal and Git.

    Skills
    LogicSyntaxTerminalGit basics
    Milestone

    Ship a first command-line program.

    start here
  2. II
    Stage 02 / 05

    Core Skills

    Pair deliberate practice with fundamentals: arrays, recursion and complexity on one side; HTML, CSS and JavaScript on the other.

    Skills
    DSA basicsRecursionHTML & CSSJavaScript
    Milestone

    Solve problems without hints and publish a personal site.

    the long middle
  3. III
    Stage 03 / 05

    Build

    Move from exercises to products. Plan, design and deploy full applications with a front end, a back end and a database.

    Skills
    ReactAPIsDatabasesDeployment
    Milestone

    Deploy a project that someone else uses.

    ship it!
  4. IV
    Stage 04 / 05

    Collaborate

    Work the way real teams work: branches, reviews, issues and shared ownership — inside the club and in open source.

    Skills
    Pull requestsCode reviewAgile habitsOpen source
    Milestone

    Get a first pull request merged.

    push & hope
  5. V
    Stage 05 / 05

    Launch

    Prepare for interviews and internships, and share what you know. The best way to master a topic is to teach it.

    Skills
    InterviewsPortfolioSystem thinkingMentoring
    Milestone

    Mentor someone through Stage I.

    pay it forward
